Lía Beluma — The Course (Phase 5)

The official Beluma course: 40 lessons from A1 to B1, in four books, built on the

canon (01–08=07) and the live dictionary (VTXT 3.6, ~1030 entries). Every lesson follows

the same textbook format so that drills and answer keys are predictable for learners and

teachers alike.

Each lesson = **objective → grammar → vocabulary (new) → examples → drills (with a hidden

answer key)**. Lesson 40 is the end-of-course project: read the paper, retell the story,

and write a letter to the Sova-Néla newspaper.

The drill format

Every drill has a label, a question area, and a key. Keys open with <details>-style

blocks in the HTML edition; in print they live on the facing page column.

Drill typeWhat it trainsKey format
D1 read-aloudsounds, stress, rhythmthe gloss + translation
D2 transformationone mechanical change (tense / plural / negation)the transformed sentence
D3 gap-fillrecall of the exact constructionthe completed sentence
D4 translationtwo-way (en ↔ be), the core skillliteral gloss + target sentence
D5 free responsecomposition, judgmentmodel answer(s)

The answer key always shows the glossed Beluma and an English rendering — the same

format the translator machine uses, so a learner can check their answers with the machine

(translator.html) when studying alone.

Using the course

  • Self-study: do the drills aloud; cover the key, answer, then reveal.
  • Classroom: each lesson is one 60–90 min session; D5 items are homework.
  • Certification: sit the sample exam at exams/ after completing book-01 (targets A1), book-02 (targets A2), book-03 (targets B1).
  • Reading practice: every lesson points at a text in the literature dossier: dialogue bank, story episodes, the Sova-Néla paper, the encyclopedia.

Course vocabulary is additive: the 8 legacy quick-lessons in lessons.html cover the same

ground as book-01 and remain a valid "20-minute" taster, but the books are the canonical

path.
