# IF-01 · The Key (Episode 1, Interactive)

**Register:** colloquial narration (canon 07 §2), identical world to
`story/episode-01-le-kela.md`. All text is dictionary-locked at **VTXT 3.9**.

## Scene 1 — Lé Véné

```
Su lé vavi séra, tu s vima-va ra lé Véné.  Lé tava-sula s luma-va.  Lé liso s
silé-va su lé néla.

Tú s héna-va o kéla su lé liso.  Tu s lósa lé kéla?
```

## Scene 2 — The Crowd

```
O misi dé lé kuma-sula s héna-va tu.  "Kvasi-la kéla?" sa nivo.
Nivo un kéma lé kéla.  Lé kéla s silé-va.

Tu s kéma ta lé kéla s tóva-va o tura dé o nésa-nira?  Tu s vima-va vél lé
Véné lé kéla-na?
```

## Scene 3 — The Morning

```
Su lé vavi séra, lé Véné s luma-va.  O misi dé lé kuma-sula sa: "Ta-lé kéla
róma lé vavi."

Míra sa: "Rona.  Lé kéla un róma lé vavi.  Lé Véné géva lé vavi;  lé kéla s
tóva-va lé tura."

Tu s héna-va lé tura.  Lé kéla s dora-va lé tura.
```

## Notes

- Minimal branching cues (yes/no implied by `Tu s lósa lé kéla?`, `Tu s vima-va vél...`).
- Uses dictionary-locked words: `vima`, `liso`, `silé`, `kéla`, `lósa`, `héna`, `kuma-sula`, `tóva`, `tura`, `Véné`, `vavi séra`, `géva`, `róma`, `rona`, `ké`/`dus` appear in canon/corpus.
- `kuma-sula` = town-folk (canon 09). `lé Véné géva lé vavi` = the river gives the morning (canon motif).
- This is a proof-of-concept IF seed (no code dependency on engine yet) — all readable in the B1 band.
