# Sova-Néla — "The Stream" · Weekly paper of Sova-Nésa

**Name note:** `sova-nela` = *language* (speech[-]stream); the paper names itself
**Sova-Néla** = *the stream*. Register: formal prose (canon 07 §1), with legal-scientific
passages where the paper quotes statutes, and columns in colloquial register.

Fixed date header format: day-name abbreviated + `po veta-misi` ("for everyone").

## Style rules for the paper (from canon 07)

1. Headlines keep verbs explicit — no headline-telegraphing.
2. Citizen names appear as roots (`Siva Pava` = Siva the father… names come from roots).
3. The paper never deviates from SVO; emphasis uses `ya` topic marker.
4. Quoting law: `ta` complement + `-ké` passive; the state is sometimes the unstated agent.
5. Weather uses plain aspect, no metaphor — metaphor belongs to the literary register.
