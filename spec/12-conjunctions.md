# §12 Conjunctions and Clause Linking — Beluma Language Standard v1.0

Status: **Normative.**

## 12.1 Coordinating conjunctions

| Beluma | Meaning |
| --- | --- |
| `e` | and (joins words and clauses) |
| `o` | or (inclusive) |
| `o… o…` | either … or … |
| `ne… ne…` | neither … nor … |
| `tamen` / `ma` | but, however |
| `kiale` | therefore, so |
| `seke` | then, next |

`e` joins any two like constituents: `luno e lavo` *a cat and a dog*;
`Mi kosa e tu síra.` *I speak and you listen.*

## 12.2 Subordinating conjunctions

| Beluma | Clause type |
| --- | --- |
| `béza` | because (cause) |
| `ke` | that (content clause) |
| `da` | if (condition) |
| `kom` | as, when, like |
| `dum` | while |
| `ante ke` | before (that) |
| `pos ke` | after (that) |
| `por ke` | so that, in order that |
| `tamen ke` | although, even though |
| `sama ke` | as if |
| `ka` / `ta` | relative pronoun (§03.7) |

- Content clause: `Mi kéma ke tu s zira.` *I know that you are fine.*
- Cause: `Mi gai, béza tu kosa.` *I go because you speak.*
- Purpose: `Mi kiva por ke mis viva.` *I work so that we may live.*

## 12.3 Conditional clauses

Real condition: `da` + clause, then result clause:

> `Da tu vena, mi rívá.` — *If you come, I will be happy.*

Counterfactual uses the conditional modal `da-va` (§6.7):

> `Da tu né vena, mi né da-va rívá.` — *If you had come, I would have been happy.*

## 12.4 Relative clauses

See §03.7. The relative pronoun agrees in role, not gender:

| Form | Use |
| --- | --- |
| `ka` | subject of the relative clause |
| `ta` | object / oblique of the relative clause |
| `ka-la` | possessive ("whose") |

> `Lé luno ka sola béla.` — *The cat that plays is beautiful.*
> `Lé luno ta mi hína sole.` — *The cat that I see is playing.*

## 12.5 Reported speech

No tense backshift. Quote directly with `sa ke…` or, colloquially, `ke…`:

> `Tu né sa ke tu vena.` — *You said that you would come (lit. that you come).*

Direct quotation uses the quote marks of §2.5 and keeps the speaker's register
(§23.3).

## 12.6 Ellipsis of the conjunction

Two closely parallel clauses may drop `e` in Informal and literary styles:
`Mi kosa, tu síra.` *I speak, you listen.* Formal and Technical prose keep the
conjunction explicit.
