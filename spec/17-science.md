# §17 Science and Measurement — Beluma Language Standard v1.0

Status: **Normative** for measurement and naming patterns; the word list is
Informative (see `lexicon/h.txt`, tag `[technical]`).

## 17.1 The scientific method in Beluma

`sienko` science, `esploro` research, `eksperimento` experiment, `mezuro`
measurement, `observo` observation, `hipotezo`, `teorio`, `pruvo` proof,
`rezulto`, `kaŭzo`/`efiko` cause/effect. A discovery is `nova-kéma` (*new
knowing*); a law of nature is `natur-leĝo` (distinct from legal `leĝo`, §18).

## 17.2 Naming disciplines and people

| Pattern | Meaning | Example |
| --- | --- | --- |
| `X-sienko` | the study of X | `saro-sienko` astronomy |
| `X-kéma` | knowledge of X | `saro-kéma` astronomy |
| `X-isto` / `X-kivor` | practitioner | `kemio-kivor` chemist |
| `X-pira` | instrument | `hurox-pira` microscope |
| `X-teorio` | theory | `gravita-teorio` |

## 17.3 The SI-style unit system

Beluma uses metric units, all registered nouns (§17.4), with Beluma spelling and
standard prefixes. Units are ordinary count nouns: `kvín métra` *five metres*.

| Quantity | Unit | Beluma |
| --- | --- | --- |
| length | metre | `métra` |
| mass | gram / kilogram | `grama` / `kilograma` |
| time | second | `séli` |
| electric current | ampere | `ampera` |
| temperature | kelvin / degree | `kelvina` / `grado` |
| amount | mole | `mola` |
| light | candela | `kandela` |
| area | square metre | `métra-kvadra` |
| volume | litre | `litra` |
| speed | metre per second | `métra po séli` |
| force | newton | `njutona` |
| energy | joule | `jula` |
| power | watt | `vata` |
| pressure | pascal | `paskala` |
| frequency | hertz | `hertza` |

## 17.4 Metric prefixes

| Factor | Prefix | Example |
| --- | --- | --- |
| 10⁹ | `giga-` | `gigabajto` |
| 10⁶ | `mega-` | `megavata` |
| 10³ | `kilo-` | `kilograma` |
| 10² | `hekto-` | `hektolitra` |
| 10⁻¹ | `deci-` | `decimétra` |
| 10⁻² | `centi-` | `centimétra` |
| 10⁻³ | `mili-` | `milimétra` |
| 10⁻⁶ | `mikro-` | `mikrograma` |
| 10⁻⁹ | `nano-` | `nanoséli` |

Prefixes attach directly to the unit; a prefixed unit is one word
(`centimétra`, not `centi métra`).

## 17.5 Reading measurements

A measurement is *number + unit (+ +/− + precision)*:

- `tuo métra e kvín` — *2.5 m* (two metres and five tenths).
- `triga grado` — *30°*.
- `diza mílisekundo`? — prefer `diza miliséli` *ten milliseconds*.
- Ranges use `a… a…`: `diza a vinta grado` *10–20°*.
- Tolerance: `plus-minus diza porsenta` *±10%*.

## 17.6 Physical and life sciences

Vocabulary follows the same head+specifier logic: `atomo`, `molekulo`,
`elemento`, `energio`, `materio`, `maso`, `forto`, `movado`, `rapido`,
`akselo`, `ondo`, `partiklo`, `nukleo`, `elektrono`; `ĉelo` cell, `gene`,
`genomo`, `proteino`, `enzimo`, `bakterio`, `viruso`, `spesio`, `evoluo`,
`ekosistemo`. A species name is `X-specio`; a subfield is the head + `-kéma`.

## 17.7 Precision and uncertainty

State precision with `presize` (*precisely*) or `sirka` (*about*): `sirka
senta grado` *about 100°*. Scientific register forbids ambiguous colloquial
degree words (`tro`) in published data; use `mésa ban` / `mísa ban` (§9.4).

## 17.8 Register

Scientific writing is **Technical** (§23.1): Arabic numerals, digit-forms for
spoken strings, SI units, `[technical]` terms. A popular-science text may switch
to Standard but must keep units and numbers consistent.
