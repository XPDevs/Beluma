# §08 Negation — Beluma Language Standard v1.0

Status: **Normative.** One clitic negates the clause; one prefix negates a word;
one particle negates a command. The three never mix inside a Standard clause.

## 8.1 The clitic `un`

`un` is a free word meaning *not*. Position: after the subject and time adverb,
**before** tense, aspect, and modals:

```
SUBJECT (TIME) un (né|wé|wés) (ASPECT) (MODAL) VERB …
```

| Example | Gloss |
| --- | --- |
| `Mi un gai.` | I do not go |
| `Mi un né gai.` | I did not go |
| `Mi un wé gai.` | I will not go |
| `Mi un s esa.` | I am not tired |
| `Mi un kima gai.` | I cannot go (same as `unkima gai`) |
| `Lé fira un s hura-va.` | The bird is not flying |

**Scope:** `un` negates the first tense/aspect/modal/verb after it. One `un` per
clause in Standard and Formal; two negatives in one clause cancel (§8.4).

## 8.2 Negating each verb class

| Class | Negation | Example |
| --- | --- | --- |
| lexical verb | `un` + (tense) + V | `Mi un né féra.` — I did not cut |
| copula | `un` + `s` | `Nivo un s esa.` — He is not tired |
| aspectual `vóta` etc. | `un` before the tense/aspect group | `Mi un né vóta kiva.` — I had not finished work |
| modal | `un` + modal, or the negative modal | `Tu un gida gai.` = `Tu unsud gai.` (shouldn't — see below) |
| existential `esto` | `un esto` | `Un esto o misi na lé tiva.` — There is no one |

Fixed modal readings (normative, from §6.6): `un gida` = *don't have to*;
`un néma` = *must not / not allowed*; `unkima`/`un kima` = *cannot*;
`unsud`/`un sud` = *shouldn't*; `un wé gida` = *won't have to*.

## 8.3 Negative imperative: `du`

`du` replaces `un` before an imperative verb — it is the only negative allowed in
slot 3 of a command:

- `Du gai!` — *Don't go!*
- `Du féra lé fura!` — *Don't cut the fruit!*
- `Du un …` never occurs: commands have no tense, so there is nothing for `un`
  to attach to.
- Polite negative request: `Téva du gai.` — *Please don't go.* (Informal/Standard;
  Formal prefers `Tu unsud gai.` — *You shouldn't go.*)

## 8.4 Double negatives

- **Standard, Formal, Technical:** two negatives in one clause **cancel**; a
  clause carries exactly one negative word. `Mi un né kima gai.` is *I could not
  go* — do not write `Mi un né un kima …`.
- **Informal:** reinforcing double negatives are permitted and stay negative (the
  dictionary's attested reinforcing items govern — §23). When unsure, write one
  negative.
- A negative inside a relative clause belongs to that clause:
  `Lé misi ka un s gavo` — *the person who is not good* (the main clause keeps
  its own polarity).

## 8.5 Derivational `un-` vs clitic `un`

| | clitic `un` | prefix `un-` |
| --- | --- | --- |
| form | separate word | hyphen-bound to the word |
| scope | whole clause | one word |
| part of speech | particle | creates adjectives/nouns |
| example | `Mi un réva.` — I am not happy | `un-réva` — unhappy |
| plural/negation | takes none | inflects like its base: `un-réva s`, `un-révas` |

- Derivations are dictionary entries or regular §15 forms: `un-kula` *easy* (lit.
  not-hard), `un-sulo` *weak*, `un-gavo` *bad*, `unkima` *cannot* (lexicalised).
- `un gida` (clitic + modal = *don't have to*) vs `un-gida` does **not** exist as
  a lexical adjective — modals are not adjectives; always write `un gida` apart.

## 8.6 `non` and negative answers

- `non` = *no* — an interjection/answer only (§7.1); it never appears inside a
  clause.
- `un` never stands alone as an answer.

## 8.7 Negative polarity (informative)

Indefinite *any/ever* items live in the negative environment:
`véta-mída` *any* (`Tu kéma véta-mída loma?` — *Do you know any tree?* —
answerable `non`). Positive sentences use *some*-forms instead
(`o véta-mída` → prefer `o loma` *a tree*).
