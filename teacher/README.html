Lía Beluma — Teacher Program & University Syllabus (Phase 5)

The official teacher-training and tertiary plan for the Sova-Nésa education system.

1. The teacher program

Who it is for: speakers ≥ B2 in the Beluma exam who want to teach.

Structure (three units, one academic year):

  1. The machine (methods). Learn the corpus tooling: how to read h.txt, how the coiner (../tools/coiner.js) validates new words, how the translator glosses. Teachers are expected to demonstrate translations in class rather than improvise vocabulary.
  2. The classroom (practice). Teach book-01 twice under supervision; mark the A1 paper with the examiner's key; record and critique your own register (colloquial vs formal).
  3. The canon (assessment). Certify on exam construction: write two A2 exam items that only use words in the VTXT-locked dictionary, and coin one new compound defensibly under canon 06.

Teacher book-standard: a certified teacher upholds these rules —

  • teach compounds before words: néla-sula is learned as water-great, one idea.
  • never mark a learner's coin wrong if it is canon-06 clean; teach it with the coiner.
  • keep the four registers visible: one sentence, taught four ways (lesson 32).

3. Translator integration in teaching

The translator is the textbook's answer key. Classroom patterns:

  • Self-correction: after a D4 translation drill, run each sentence through the translator and compare glosses.
  • Discovery: ask "does the machine accept wégai?" — then use the wégai entry to teach that fusions are spoken-only (canon 07) and must not appear in formal writing.
  • Coining lab: a learner proposes luma-tiva (light-room?); the class checks the dictionary, runs the coiner in dry-run (node ../tools/coiner.js --dict ../h.txt), and sees the V1–V5 verdicts. That is the whole lexicography grade in one activity.

4. Admin

  • Session sizes: ≤ 12 for oral work; the exam oral is 1:1.
  • Materials live in ../course/, exams/, ../library/; keep local copies to the current commit so learners always sit the same vocabulary set (the dictionary is version-locked by VTXT).
