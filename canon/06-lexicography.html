Every entry added by the machine or by hand must be validated against this canon and

The dictionary is a catalog of attested words, not a closed list. The compounding

engine already understands any root+root word; entering a word in h.txt just fixes its

reading and gloss. Two engines therefore grow the language:

  1. the grammar engine (compounding + affixes) which is infinite;
  2. the lexicon engine (this canon + tools/coiner.js) which attests the frequent words.

2. Phonotactics (hard constraints)

Words must be sayable under the 23-letter system — one letter, one sound (j=y, r rolled,

x=ks, w=w).

  • Vowels: a e i o u. Five, one sound each.
  • No letters c, q, y — use k, w/v.
  • Syllable shape: (C)V(C), open-favouring. ne-sa, li-sa, fu-ra.
  • Allowed onset clusters (codex-observed, exhaustive): - stop/r: pr tr kr br gr dr fr vr sr - stop/l: pl tl kl bl gl fl vl sl - kv (and the read-out tv? no — only kv), st.
  • Allowed word-final codas: s n r m l k (and x = /ks/).
  • No tri-consonant clusters; no clusters across a syllable break except the allowed coda + allowed onset (in-ves-ta, im-por-ta).
  • Default stress: penultimate; the acute accent marks any other stress and is always optional in writing.
Validator check (permitted): `/^(?:[abdefghijklmnoprstuvwxz]prtrkrbrgrdrfrvrsrpltlklblglflvlslkvst)(?:[aeiou](?:[snrmlk]x)?(?:[aeiou](?:prtrkrbrgrdrfrvrsrpltlklblglflvlslkvst))?)*$/-ish — enforced in code, simpler to trust tools/coiner.js`.

3. The four coining tiers

Tier 1 — transparent compound (never skip it). Head-first: main meaning first,

specifier(s) after. This is home territory and supplies ~80% of future words.

vosa-zanva = body+defense = immune system; koma-meda = pain+medicine = painkiller;

saro-kémor = star+knower = astronomer; gava-kora = money+box = wallet.

Rules:

  • existing root(s) only, joined with -;
  • the head root determines category (noun head → noun),
  • listed entries win over generated ones when both exist (the listing fixes the reading).

Tier 2 — affix-regular derivation (do NOT list). The glosser handles

-s -as -la -nira -sula -va -ké -or -os -ét -an -lek -ik -lé -ji, prefixes

un- ni- ré-, tool -pira, platform -tavi. Listing them is redundant — except where

the form has taken on an unpredictable sense (e.g. nela-sula = ocean, not just "big

water"), which is exactly when it should be listed.

Tier 3 — dedicated root (for non-compositional concepts). When no transparent

compound says it. Must be collision-free against h.txt, respect phonotactics, and avoid

near-clone of an existing root (e.g. don't add mune next to muna/existing). One

meaning duty — no two new roots that mean the same thing.

Tier 4 — international loan (academic/technical register). Respelled to (C)V(C),

open syllables preferred, then glossed with (loanword) tag. Permitted where the concept

is genuinely international and the everyday tier is too heavy (Comet, galaxy, robot,

atom). Everyday synonyms keep Tier 1 forms:

kometa (comet) but nela-gaza (steam = water-gas); planeta but hula-gai-or

(astronaut = sky-goer).

4. Semantic-field taxonomy (the catalog of the world)

Each field is a working set of head concepts, documented with a template line per

high-frequency seed. Language must cover: astronomy, biology, chemistry, physics,

mathematics, computing, economics, law, politics, medicine, engineering, military,

emotions/psychology, religion/philosophy, music, sports, food/everyday, slang.

The machine batches are keyed by these fields (tools/domain-data.js).

5. Homonym policy (documented; they exist)

Beluma tolerates homonyms by design (mila thousand/my, koro bear/really?, rá near/was).

New coinages must NOT introduce homonyms with core grammar words (s vóta kéma …) —

the machine rejects those. Register/context disambiguates the rest.

7. Validation checklist (enforced by tools/coiner.js)

  1. phonotactic regex passes;
  2. no exact collision with h.txt or a pending entry;
  3. not a core-grammar homonym (wés, vóta, s, un, gida, …);
  4. no suffix/prefix trap (a new word must not parse as an existing stem + affix with a contradictory meaning — the generator warns);
  5. gloss is in English, primary sense first, alternatives after /;
  6. field batch header matches the taxonomy key.

Run: node tools/coiner.js (dry-run to out/) then merge validated lines into h.txt.
